Privacy and your data

Updated 29 October 2026. OpenWorld is operated by Nir Feinstein. For access, correction or removal requests, use the contact form or email fainir2006@gmail.com.

What the studio saves

An account stores your email, username, a password hash and account metadata. Saved sessions contain prompts, assistant messages, version descriptions and generated game files. Public sharing, publishing and suggestions happen only when you choose them. Sharing makes that game and its public description available to anyone with the link; it does not expose your private chat or version history. Public copies may be downloaded by other people.

You can explore the base game without an account. Guest editing uses a random private capability stored on this browser. Keep this device data to reopen guest edits; the operator cannot automatically prove ownership if it is lost. There is no account-recovery email service in this release; contact the operator for a reviewed ownership request.

AI and service providers

You supply your own Anthropic key and explicitly send a game-edit request. OpenWorld forwards the prompt, relevant game source, chat context and any attached image to Anthropic to produce the change. The request includes your key for that call; raw keys are not saved in the server database or application logs. Anthropic's service terms and retention also apply. No payment is collected by OpenWorld.

Railway hosts the application, account database and saved games. Existing Three.js assets are loaded through jsDelivr or unpkg; the game sandbox allows only the documented asset hosts. These providers receive the ordinary network information needed to serve requests. The contact form stores your submitted name, email and message for the operator; it does not send marketing email.

This browser

The studio saves its sign-in token, account display information, guest capability, current session/version, recent chat, panel preferences and your API key in local storage. This keeps them across visits on this device. The isolated game cannot read the studio's storage; game cosmetic preferences are temporary and reset on reload. Use Your account → Forget saved API key to remove the stored key; close or reload other studio tabs to clear an in-memory copy. Signing out clears studio account credentials and the saved key on this device.

Google Analytics, Mixpanel and Betterloop are optional and stay off until you allow them using Analytics choices. Only configured providers load. Google receives sanitized public page context and fixed events, with advertising personalization and Google Signals disabled. Mixpanel receives fixed events and a random browser identifier created after consent, with IP geolocation disabled. Betterloop records structural interactions, browser errors and performance with text capture disabled. No prompts, chat content, keys, account data, query strings, fragments or version IDs are sent. Account, admin, contact, private-version and game pages are excluded. There is no session replay. Do Not Track and Global Privacy Control keep optional analytics off. Withdraw at any time to stop new measurements, discard queued Betterloop events and clear accessible analytics identifiers. This cannot recall previously sent data or requests already in flight. Provider retention settings apply. Optional website analytics is off. Server request addresses are used briefly in memory for abuse limits, without being stored in the account export. Hosting providers may maintain their own operational logs.

Export and account removal

Your account can download your profile, saved chats, version information and owned game files. The export excludes password hashes, sign-in tokens, guest proofs and API credentials. Contact the operator if the export exceeds the 512 MB safety limit.

Closing an account requires the current password and typing DELETE. It removes the account, its saved chats, active game files, public shares and stars. Other accounts are preserved. Copies another person downloaded cannot be recalled. If you submitted a contribution and the operator approved it, its HTML may already have been copied into the shared base game. Account closure removes your saved version and its links, without silently reverting that shared game for everybody; contact the operator about removal of that separate public copy. Contact messages were submitted separately and are not linked to an unverified signup email; request their removal through the operator, who may check ownership before acting.

Server recovery keeps the latest seven snapshots, normally made every12hours. The existing independent encrypted Mac mirror also keeps up to seven copies; the Mac must be awake and authorized for new copies. Older snapshots can contain removed data until they rotate, and copies can persist longer if backups stop. Account-ID-only deletion evidence is retained separately and in new snapshots. The documented restore command requires surviving current deletion evidence and applies it before a restored service may run, so older backups cannot reactivate removed accounts. The operator must use the latest surviving evidence when restoring an older copy.

Retention and choices

Account/game data stays while your account is useful or until you remove it. Contact messages stay while relevant to the request; ask for correction or removal at any time. The minimal removed-account IDs are retained to prevent restoration of deleted records. No automatic marketing sequence or sale of account data is part of this product.

Optional website analytics

Analytics is off unless you allow it on this device. If configured and enabled, Google Analytics, Mixpanel and Betterloop receive basic page, device and fixed interaction events. Prompts, chat text, keys, account details and game/version identifiers are not sent. Private versions, account, contact and admin pages are excluded. Do Not Track and Global Privacy Control keep it off.
